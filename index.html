His research contributions include cryptographic algorithms and secure communication frameworks for IoT systems, and he has published extensively in SCI-indexed journals and peer-reviewed conferences.

Current work centers on lightweight cryptographic techniques for IoT, wireless sensor networks, and cyber-physical systems — designing energy-efficient encryption that reduces computational overhead while maintaining strong security for next-generation networks.

01 Research

Enhancing Privacy and Security of Robust IoT Networks — Ph.D. thesis

With connected IoT devices expected to reach 40 billion, and the address space of IPv4 already outpaced, IoT networks present an open attack surface over insecure wireless channels. This work addresses that gap in three parts: a Secure Addressing and Identification (SAI) scheme that modifies the standard IPv6 format to authenticate users and appliances at the server while filtering incoming packets by device identity; a Secure Session Key based mutual authentication scheme (SSKUAI) built on Diffie–Hellman key exchange, verified formally through the Real-or-Random model and the AVISPA tool against device compromise, password guessing, man-in-the-middle, replay, and masquerade attacks; and a Smart-Card Secure Addressing and Authentication scheme (SCSAA) that assigns a unique 64-bit interface identifier to each device.

Distributed Recovery in Moveable Wireless Sensor Networks — M.Tech thesis

Wireless sensor networks rely on relay nodes to maintain data consistency; the failure of a cut-vertex node partitions the network and disrupts communication. This thesis develops an autonomous technique to identify failed nodes and recover from network partitioning in distributed, mobile wireless sensor networks.
